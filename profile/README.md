## Eon AGI

*Intelligence That Endures*

Eon AGI explores how memory, self-improvement, and continuous interaction can make AI intelligence endure over time.

You don't need an IQ of **130** to be human, nor does an agent need **Claude Mythos** to exhibit "pseudo-AGI".
